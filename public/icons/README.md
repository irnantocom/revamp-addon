# Icon Files

This directory should contain the following icon files:

- icon-16.png (16x16 pixels)
- icon-32.png (32x32 pixels)
- icon-48.png (48x48 pixels)
- icon-128.png (128x128 pixels)

## Creating Icons

You can create icons using any image editor. The icons should:
- Be square
- Have a transparent background (PNG format)
- Represent the extension (e.g., a stylized "R" or editing symbol)
- Be visually consistent across all sizes

## Temporary Workaround

For development, you can use any PNG files with the correct dimensions, or use an online icon generator.

Recommended tools:
- Figma (free)
- Canva (free tier)
- Online favicon generators
